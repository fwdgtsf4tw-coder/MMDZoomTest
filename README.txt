MMDZoomTest 0.1

Purpose:
- Experimental FOV-only controller for MikuMikuDance 9.32 x64.
- Uses MMD's standard FOV edit control (control ID 448).
- Does NOT register camera keys.
- Does NOT save PMM files.
- Does NOT write directly to MMD memory.

Test with a new/throwaway PMM first.
Run MMD and this EXE at the same Windows privilege level.
Move the slider and verify that MMD's FOV changes.

This is a measurement/probe build before adding ZOOM conversion and key registration.
